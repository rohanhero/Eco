# 🌈 Frontend Setup (React + TypeScript 💅)

```sh
cd frontend  # go into frontend like you're entering Narnia
npm install  # install dependencies like your life depends on it
npm run dev  # run the dev server and pray it works
```

After this, open your browser and type:

```
http://localhost:5173
```

If it doesn't work 👉 **skill issue**

---

# 🐍 Backend Setup (Django REST Framework 🔥)

```sh
cd backend  # diving into backend abyss
py -m venv venv  # creating virtual environment because global installs are illegal
venv\Scripts\activate  # wake up the environment
pip install -r requirements.txt  # feed the snake (python dependencies)
python manage.py migrate  # apply migrations like mech applying vicks
python manage.py runserver  # launch rocket
```

Now open:

```
http://127.0.0.1:8000
```

If you see errors, relax, it's Django's love language 💕
